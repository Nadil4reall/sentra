How SENTRA works

Six separate decisions, from observing a server to verifying an approved change.

  1. 01Collect Host Evidence

    Understand the current Linux server.

    M3
  2. 02Analyze Compatibility

    Evaluate applicability, dependencies, uncertainty and known conflicts.

    M4
  3. 03Validate in Sandbox

    Test the proposed change in an isolated environment.

    M6
  4. 04Review & Approve

    An administrator reviews evidence before deployment.

    M8 approval
  5. 05Deploy to Target

    The enrolled Agent executes the approved control.

    M7
  6. 06Verify Result

    Collect fresh target evidence and verify the post-enforcement state.

    Fresh verification
Sandbox validation does not modify the target server.No known conflict does not mean compliant or safe.Administrator approval does not itself deploy a change.Final verification uses fresh evidence from the real target.
